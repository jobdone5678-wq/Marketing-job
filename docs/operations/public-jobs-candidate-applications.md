# Candidate-specific Public Jobs lists

Public Jobs has **Available to apply** and **Applied jobs** lists. Recruiters, technical recruiters and super admins select a candidate using **Find roles for a candidate**. Candidates use their own saved profile automatically.

A successful submission moves the posting out of Available for that candidate only. The same posting remains available for another candidate who has not applied. Opening the external form, preparing a packet, a Draft, a submit attempt and a failed submission do not count as an application.

The lists use the same job submission records across the recruiter, candidate and super-admin portals. Current assignment and ownership checks still apply. A former recruiter cannot read a candidate who is no longer assigned to them.

The portal and company filters also apply to Applied jobs. That history uses application dates and retains older or closed postings, including applications recorded from an extension without a saved catalog job ID when the precise posting URL is known. Matching uses saved job IDs or posting URLs, including public query-based job identifiers; it does not match a company or job title alone.

Return to Public Jobs after submitting to refresh the candidate's Available list, or use **Refresh jobs**. Open **Applied jobs** to view the application and follow **Application history** for the submitted resume, answers and later recruiting stages. Choose another candidate to see their independent lists. Super admins can inspect any candidate; staff can inspect only assigned candidates.

This is a portal/API change and requires no extension update or database migration.

# Public jobs and staffing-company directory

Apply `supabase/migrations/20261014000300_public_vendor_import.sql` to the production Supabase database before using **Import selected companies**. It creates a service-role-only, insert-only import function. The script is standalone and can be rerun. No API keys or additional job provider integrations are required.

In the Public, Greenhouse, or Ashby jobs page, choose a company under **Explore public company boards**, then **Fetch selected board**. Recruiters and administrators can use **Save source to directory** to include the board in subsequent **Pull & Save Jobs** requests. Saving an existing source preserves its name and enabled/disabled setting. An empty source directory uses the catalog; an intentionally disabled directory stays disabled. Candidates can preview catalog boards and cache jobs from existing sources; registering a new configured source requires a recruiter or administrator. Job fetches use the existing public ATS adapters, technical-role filter, and resume-related ranking. Cache writes use batches of 100 jobs.

The catalog includes Ramp (Ashby), Figma, OpenAI, Stripe, Cloudflare, Canonical, Notion, Linear, and Supabase. Ramp's previous Greenhouse preset was replaced with its current public Ashby board. Existing saved source records are preserved; save Ramp's Ashby source and disable an obsolete Greenhouse source through your existing source administration as needed.

Under **Prime Vendors Directory**, review the official source and careers links, select companies, then import. The catalog contains TEKsystems, Robert Half, Kforce, Randstad USA, and Insight Global. Imported records retain source URL and check date. Headquarters, partner tier, commercial terms, responsiveness, rating, and recruiter contacts are not inferred. Matching existing directory IDs, company names, or website domains are skipped, including records edited by staff. Concurrent imports serialize to avoid duplicate import records.

Primary source pages checked on October 14, 2026 are linked directly in `src/lib/public-directory.ts` and in the UI. Public Ashby API payloads were also inspected for Ramp, Notion, Linear, and Supabase. Shell-based external network verification was unavailable in the sandbox; provider failures remain visible in the live fetch result. No production database or hosted jobs were modified during implementation.

Validation: PGlite executes the import migration and tests repeat imports, edited records, matching manually entered websites, and authenticated-role permission denial. API tests reject unauthorized users and arbitrary company IDs. Browser tests exercise exact ATS provider selection, source saving, official source links, vendor selection and import results.
